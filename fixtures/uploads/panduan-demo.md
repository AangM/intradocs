# Panduan Demo M2a

Dokumen sintetis untuk mencoba upload. Bukan prosedur atau kebijakan Telkom.

## Tujuan

Memeriksa bahwa draft dapat dibaca pemilik, tetapi tidak muncul pada pencarian Published.

## Langkah contoh

1. Gunakan akun Contributor.
2. Pilih kategori Infrastruktur.
3. Bandingkan reader dengan berkas original yang diunduh.

| Pemeriksaan | Hasil yang diharapkan |
| ----------- | --------------------- |
| Status      | Draft                 |
| Publikasi   | Belum ada             |
| AI          | Nonaktif              |

## Catatan

Tidak ada password, token, hostname internal, atau data pribadi dalam contoh ini.
